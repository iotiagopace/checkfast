# 🚗 CheckFast — Landing Page de Franquias

Landing page de alta conversão para captação de franqueados da
**CheckFast Vistoria Veicular**, desenvolvida com React.

Projeto gerado e iterado com **Claude (Anthropic)** como ferramenta
principal de desenvolvimento, copy, SEO e design system.

## Stack

- React 18 (componente funcional, hooks)
- CSS-in-JS via inline styles + CSS variables
- Google Fonts — Barlow Condensed + DM Sans
- Sem dependências externas (zero libs de UI)

## Estrutura

checkfast-franquias-lp/
├── checkfast-franquias-lp.jsx   # componente principal
├── CheckFast_Design_System.md   # tokens, componentes, padrões
├── LP_CheckFast_Franquias_Copy_Revisada.md  # copy completa
└── SEO_Audit_CheckFast_Franquias.md  # audit SEO + keywords

## Seções da LP

Hero + formulário → Trust bar → Autoridade → Mercado →
Posicionamento → Serviços → Diferenciais → Comparativa →
Suporte 360° → Modelos → Investimento → Processo →
FAQ accordion → CTA final → Footer
