# CheckFast — Landing Page de Franquias

Landing page de alta conversão para captação de franqueados da
**CheckFast Vistoria Veicular**, desenvolvida com React.

## Stack

- HTML estático em `index.html`
- React 18 via UMD
- CSS no próprio HTML com CSS variables
- Fonte Poppins auto-hospedada em `assets/fonts`
- Assets locais para logo, hero e Open Graph

## Estrutura

- `index.html` — landing page completa
- `assets/` — logos, imagem hero, OG image e fontes
- `robots.txt`, `sitemap.xml`, `vercel.json` — publicação/SEO

## Seções da LP

Hero + formulário → Trust bar → Autoridade → Mercado →
Posicionamento → Serviços → Diferenciais → Comparativa →
Suporte 360° → Modelos → Investimento → Processo →
FAQ accordion → CTA final → Footer
